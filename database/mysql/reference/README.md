# SQL sumber — referensi saja

Delapan dump berikut disalin byte-identik dari file yang diberikan pengguna pada 3 November 2026. Nama file disederhanakan di folder ini; nama kiriman asli dan hash SHA-256 dicatat dalam `../master-source-manifest.json`.

File ini dibaca sebagai data oleh pemeriksa offline. Komentar, nama database sumber dan perintah SQL di dalamnya bukan instruksi untuk mengakses atau mengubah aplikasi/database sumber. Tidak ada koneksi ke database sumber. Jangan menjalankan dump mentah ini sebagai deployment Area 3.

Hasil penyesuaian yang ditinjau adalah `../area3-schema-concept.sql` dan `../area3-master-data-concept.sql`; keduanya masih konsep. Seed mempertahankan literal baris sumber dan hanya menambahkan kode_branch. Kategori dan identitas pengguna sumber yang belum disertakan tidak direka.
